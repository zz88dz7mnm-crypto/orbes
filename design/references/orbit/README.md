# ORBIT — pendiente del dueño

ORBIT es una app propia del dueño y sirve de referencia para la esfera "ORBIT futurista" del modo reloj (informe §6.4).

Mientras no haya descripción, el código implementa una **interpretación propia**: anillos concéntricos para horas, minutos y segundos, con puntos que orbitan, y ORBEX en el centro.

Para que se parezca a ORBIT de verdad, dejar acá:
- Capturas (colores, formas, tipografía).
- Cómo se comporta (animaciones, qué información muestra, interacción).
- Qué conservar tal cual y qué "mejorar y hacer más futurista".
- Código de ORBIT si se puede compartir.
